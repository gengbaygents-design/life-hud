PHASE 7 — REMINDER + ARCHIVE FOUNDATION has passed acceptance.

turn the currently functional LIFE HUD into a coherent, polished, daily-usable personal operating system.

==================================================
TYPOGRAPHY
==================================================

Refine type hierarchy.

Suggested conceptual hierarchy:

Display
Page Title
Section Title
Card Title
Body
Meta
Micro Label

Avoid:

- too many all-caps labels
- overuse of letter spacing
- tiny unreadable metadata
- excessive monospace styling

HUD labels may use restrained tracking,
but body copy should remain comfortable.

Chinese readability is a priority.

==================================================
COLOR
==================================================

Preserve dark blue-black foundation.

Use restrained cool blue / ice-blue accents.

Avoid:

- pure black everywhere
- electric cyan everywhere
- bright neon borders
- too many accent colors
- high-saturation gradients

Accent should guide attention,
not decorate every element.

==================================================
BACKGROUND / SPACE ATMOSPHERE
==================================================

Create/refine a subtle space atmosphere.

Allowed:

- faint starfield
- extremely slow parallax if already easy
- sparse particles
- very subtle orbital lines
- slight ambient gradients

Do not:

- animate aggressively
- distract from reading
- use large bright nebula backgrounds on ordinary screens
- make text contrast unstable

Atmosphere should almost disappear when the user focuses on content.

==================================================
CARD SYSTEM
==================================================

Normalize cards.

Prefer a small number of card variants:

GlassCard
HUDCard
FocusCard
QuietCard
AlertCard

Do not nest cards inside cards without real hierarchy need.

Cards should have:

- consistent padding
- consistent border opacity
- consistent corner radius
- clear title/body separation

Avoid every block looking equally important.

==================================================
HOME — HIGHEST PRIORITY
==================================================

HOME gets the strongest polish.

Canonical principle:

HOME tells you what matters now.

Current screenshot is structurally correct,
but improve visual hierarchy significantly.

HOME should feel calmer and more intentional.

Mobile priority:

1. greeting / contextual header
2. CURRENT or NEXT
3. Today
4. compact STATUS
5. Lim brief / presence
6. subtle Voyage context

Do not make the page long without reason.

==================================================
HOME FOCUS CARD
==================================================

NEXT / CURRENT should be the dominant card.

When empty:

do not leave a huge visually heavy empty rectangle.

Current text such as:

“此刻，可以留白。”

is valid.

But visually,
empty-state card should feel lighter than an urgent action card.

Differentiate:

ACTIVE FOCUS
vs
QUIET FOCUS

without breaking layout.

==================================================
HOME — EMPTY STATE
==================================================

Do not leave:

No call-to-action needed unless useful.
