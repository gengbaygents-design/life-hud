## GOLDEN MVP JOURNEY

The eventual MVP should support:

1. Open HOME.
2. See next class / current relevant event.
3. Tell Lim about homework.
4. Assignment + linked Task + Reminder are created.
5. Record a simple status moment.
6. Capture a Learning Record from an image/link/thought.
7. Ask "Lim, what should I do now?"
8. Receive one main recommendation + one fallback.
9. Complete the Task.
10. Assignment may become work DONE but remains NOT_SUBMITTED.
11. User explicitly says it was submitted.
12. Assignment becomes SUBMITTED.
13. Reload.
14. Data remains correct.
15. Use another device.
16. Data remains correct.
17. Disable AI.
18. Core system still works.
