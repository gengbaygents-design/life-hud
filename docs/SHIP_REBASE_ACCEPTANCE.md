## 本次修正与限制

Docker 默认目录继承 EFS 时发生同目录 EXDEV；配置已备份并通过项目内实体/进程路径修复，未修改系统加密或恢复出厂设置。Docker 自身用户目录例外由用户明确批准；详情见 [容器记录](CONTAINER_SETUP.md)。

PostgreSQL 初次初始化的临时 socket 服务不能作为宿主 TCP 就绪证据，健康检查已改为 TCP；迁移仅对明确连接瞬态作有限重试。身份/删除使用事务，密码重置撤销旧会话；错误信息只输出安全错误码。限流没有关闭，验收遵守 Retry-After。

Ship 的模式环境文件曾将 API 指向 localhost，而页面为 127.0.0.1，导致浏览器拒绝 SameSite=Lax Cookie；根配置现派生开发/生产本地覆盖文件，并向启动进程传递公开 Vite URL。Cookie 保持 HttpOnly / Lax。首次对话提前改 URL 导致组件重建、输入恢复失效，现改为回复成功保存后跳转，并新增浏览器回归。

当前只交付基础：没有 LIFE HUD 业务实体、完整 File 元数据/知识处理、完整 Lim、权限化上下文或行动系统。没有真实在线 AI 回复验收；本阶段按要求验收缺少密钥时的清晰失败。Drizzle 1.0.0-rc.4 的 PostgreSQL、迁移和认证兼容性已实测，后续依赖升级仍需复验。未开展公共部署。
